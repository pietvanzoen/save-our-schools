# Housing sources

Primary material about housing developments that bear on school attendance areas (unit counts, unit mix, addresses).
Each folder has a `_manifest.json` with URL, fetch time and checksum.

| Folder | Publisher | Contents |
|---|---|---|
| `homeforward/` | Home Forward (Housing Authority of Portland) | Stephens Creek Crossing property page (6715 SW 26th Ave): 122 units and the unit mix by bedrooms |

Parcel-level data (Multnomah County assessor taxlots and City of Portland address points, via Portland Maps) is in
`../gis/portlandmaps/`, one folder per study area, with a `_manifest.json` recording the exact query.
