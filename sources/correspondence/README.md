# Correspondence

Letters and emails sent to the PPS Board or staff by public officials, kept verbatim. Each file is stored exactly as
received; `_manifest.json` records who sent it, to whom, when, how the archive got it, and a SHA-256 checksum.

Cite as `[LTR:<file stem> L<line>]`, where `L<line>` is the line number in the stored file (for example
`[LTR:2026-10-13_rep-dacia-grayber_maplewood-closure L23]`). `tools/search.py --kind correspondence` searches these files.
