# Vendor transcripts

Word-level speech-to-text exports of PPS meeting videos, supplied by the repository owner. They are primary material:
never edit them. See `_manifest.json` for provenance and checksums.

The vendor's speaker tags are automatic and often wrong (letters are reused for different people, and some named tags
are mis-assigned). Use the checked speaker labels in `analysis/speaker_transcripts/` instead.
