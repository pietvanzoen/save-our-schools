# People: PPS board members and senior staff (2025–2026)

Profiles of the people who shape the 2026 rightsizing/school-closure decision, built from ~1,440 verified transcript quotes, official votes and news-reported quotes. Compiled 2026-10-11.

## Files

| File | What it is |
|---|---|
| `quotes_all.jsonl` | All transcript quotes merged from `quotes/batch00–09` and `batch10_redo` (1,443 records; no duplicates on video + timestamp + person). Sorted by date, then seconds. Adds `source_batch`; adds `person_as_recorded` where a name was normalized. All confidence levels kept. |
| `positions_timeline.csv` | One row per high/medium-confidence quote on a policy topic, plus one row per person per key vote: `person, date, topic, stance, quote_ref, confidence` (+ `all_topics`, `source_type`). |
| `<slug>.md` | One profile per person (list below). Each has roles/committees, a position summary by topic, a dated "how their thinking changed" narrative, a voting table, and key quotes. |
| `quotes/` | Source batches and per-batch notes (inputs). |
| `_quotes_from_news.jsonl`, `_roster_from_web.md` | Inputs (news quotes; roster). |

**Name normalization.** "Eddie Wang" / "Edward Wang" / "Edward (Eddie) Wang" → **Edward (Eddie) Wang** (roster form). "Philip Hristic" / "Filip Hristić" → **Filip Hristić** (BoardBook minutes spelling). Other names were already consistent. Captions routinely garble names (e.g. "Wong", "Lefort", "Englesman", "Split", "to pass", "Michelle Chase Miller"); the batch notes list the mappings.

**Caveats.**
- YouTube auto-captions carry no speaker labels. Attribution confidence is in every record. Profiles use only high and medium quotes and flag medium ones *(medium)*; low-confidence quotes (25 records) are excluded from all syntheses and from `positions_timeline.csv`.
- The roster is partly outdated: Rashelle Chase-Miller became Vice-Chair on July 7, 2026 [BB:14305225 p.1]; Wang (Chair) and DePass (Vice-Chair) were re-elected Jan 13, 2026 [BB:3998053 p.3].
- Several 2026 votes come from video roll calls because minutes are missing or self-contradictory (noted in each table).
